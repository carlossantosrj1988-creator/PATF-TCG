# PATF TCG — Bootstrap de Contexto

Antes de qualquer tarefa nesta sessão, leia o contexto na ordem abaixo.

## 1. Estáveis (sempre ler)

Identidade do projeto, regras absolutas e estado geral. Raramente mudam.

- `Claude memory/PATF-DEV-01_instrucoes.md` — quem o Claude é (identidade, regras absolutas, Regra de Interface do canvas híbrido, zonas reservadas)
- `Claude memory/PATF-DEV-01_sistema-contexto.md` — como o próprio sistema de contexto funciona
- `Claude memory/NOVO-DEV-01_contexto-base.md` — arquitetura, regras de construção, progresso geral (marcos por data)
- `Claude memory/PATF-DEV-01_fluxo-game.md` — fluxo entre telas, estrutura de dados (`CHAR_POOL`, `PLAYER_STATE`)
- `Claude memory/PATF-DEV-01_roteiro-game.md` — visão geral, regras de jogo, mecânicas conceituais

## 2. Última sessão (sempre ler)

Continuação direta — narra o estado de entrada, o que foi feito, decisões tomadas e a "Próxima Sessão" que define o foco de agora.

- Listar `Claude memory/sessoes/` e ler o arquivo `sessao-XXX_*.md` com o número mais alto.

## 3. Sessões anteriores (histórico)

Não ler por padrão. Consultar pontualmente apenas se a tarefa exigir resgate de decisão antiga ou contexto específico.

---

*Modelo: estáveis ficam no bootstrap; sessões anteriores ficam de histórico navegável. A última sessão sempre carrega o que vem a seguir.*
