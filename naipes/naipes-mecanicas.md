## Ciclo de Vantagem

```
♥ COPAS → ♣ PAUS → ♦ OURO → ♠ ESPADAS → ♥ COPAS
```

Leitura: A → B significa A tem **vantagem** sobre B.

| Naipe       | Vence       | Perde para  |
|-------------|-------------|-------------|
| ♥ Copas     | ♣ Paus      | ♠ Espadas   |
| ♣ Paus      | ♦ Ouro      | ♥ Copas     |
| ♦ Ouro      | ♠ Espadas   | ♣ Paus      |
| ♠ Espadas   | ♥ Copas     | ♦ Ouro      |
